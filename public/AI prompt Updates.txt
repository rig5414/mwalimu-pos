🏗️ ARCHITECTURE
Tech Stack
- Frontend: React 18 + Vite + React Router v6 + Zustand
- Desktop: Electron 29
- Styling: Tailwind CSS v3 + admin/POS glass tokens (`posTheme.js`, `globals.css`)
- Charts: recharts (admin dashboard)
- Database: SQLite (better-sqlite3), WAL, foreign_keys ON
- IPC: window.api (contextBridge) → handlers return `{ ok, data }` | `{ ok: false, error }`
- IDs: uuid v4 for PKs
- Category icons: `categories.icon_data` BLOB + `useIconDisplay` hook; emoji `icon` text fallback

Category model
- Unlimited-depth tree via `categories.parent_id`
- Products attach to **leaf** `category_id`; optional `school_id` for school badge on variant
- POS/stock browse uses **category IDs**, not name paths
- Display paths: `category_path[]`, `path_label` from `getCategoryPathNames`

Key frontend modules
- `src/lib/categoryBrowse.js` — ID browse state + breadcrumbs
- `src/lib/hierarchyNav.js` — search, barcode, display breadcrumb (name-based labels)
- `src/lib/categoryTree.js` — admin tree flatten / labels
- `src/components/admin/CategoryPicker.jsx` — searchable leaf picker
- `src/components/ImageUploader.jsx` + `src/hooks/useIconDisplay.js`
