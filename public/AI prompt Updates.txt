🏗️ ARCHITECTURE
Tech Stack
- Frontend: React 18 + Vite + HashRouter + Zustand
- Desktop: Electron 29
- Styling: Tailwind CSS v3
- Database: SQLite (better-sqlite3)
- IPC: window.api (contextBridge)

Project Structure
mwalimu-pos/
├── electron/
│   ├── db/migrate.js        # SQLite schema
│   └── ipc/handlers.js      # All DB operations (No dummy fallbacks allowed in src)
├── src/
│   ├── pages/               # All React pages (Strictly DB-driven via window.api)
│   ├── store/               # Zustand stores (auth, cart)
│   └── components/pos/      # POS specific components (Cart, Payment, Receipts)
├── seed_sample_data.js      # Realistic data seeder (Run via npx electron seed_sample_data.js)
└── public/AI prompt Updates.txt # This status tracker

📝 CODING STANDARDS
1. No Dummy Data: All production pages MUST use `window.api`. Fallbacks are for browser dev mode ONLY.
2. Async/Await: Use modern async patterns for all IPC calls.
3. UUIDs: Generate `uuidv4()` in the backend for all new records.
4. Transitions: Wrap multi-step DB writes in `db.transaction(() => { ... })()`.
