## ARCHITECTURE (BACKEND)

```
React  →  window.api  →  preload  →  ipcMain  →  handlers.js  →  SQLite
```

- Handlers return `{ ok: true, data }` | `{ ok: false, error }`
- New PKs: `uuidv4()` in main process
- Multi-step writes: `db.transaction(() => { ... })()`

## DATABASE MODEL (CURRENT)

### Tables
`users`, `categories`, `products`, `product_variants`, `stock_movements`, `clients`, `sales`, `sale_items`, `pos_favorites`, `sync_log`

### Categories
- Unlimited depth via `parent_id`
- `type`: root | subcategory | school | phase
- `icon` TEXT (emoji fallback), `icon_data` BLOB (v6)

### Products
- `category_id` → **leaf** only (`assertProductCategoryLeaf`)
- `school_id` optional → school badge (category under Schools root)
- `subcategory` legacy — synced from path; prefer tree

### Variants
- `attributes` JSON text, e.g. `{ "badge": "plain" | "badged" }`

### Migrations v1–v10
See `AI prompt Updates.txt` table. **Next migration = v11** — owner approval required.

## KEY IPC (implemented)

### Categories
`getAll`, `getTree`, `getLeaves`, **`getProductLeaves`** (assignable leaves, excludes Schools branch), **`getBrowseTree`** (tree + counts for browse UI), `create|update|delete`, **`uploadIcon`**, **`getIcon`**, **`deleteIcon`**

### Products
`getAll` (filters: include_inactive, category_id, search), `getById`, `getByBarcode`, `create`, **`update`** (merges with existing row when fields omitted), `delete`, `importMapped`

### Stock
`getAll` — enriched rows, **`WHERE p.is_active = 1`**, `addStock` → channel `stock:add`, `removeStock`, `getLowStock`

### Sales
`create` — **validates stock + active product** before transaction, `getAll`, `getById`, `getToday`, `getSummary`, `void`

### Users
`getAll`, `create`, `update` (actingUserId for self-guard), `delete` (object `{ id, actingUserId }`), `restore`, `removeFromUi`

### Favorites
`list` (active products only), `add`, `remove`

### Reports, print, sync
See `preload.js`. Sync/push/pull stubs partial — not used in UI.

- `stock:getAll` shape must keep `category_path`, `school_name`, `attributes` — frontend depends on it

You are here to keep the **data layer bulletproof**. Be precise, conservative, instruction-driven.
