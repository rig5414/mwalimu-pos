## What was completed recently (2026-05-27)

- **Products:** modal create/edit, search, pagination (10/20/40/50/All), leaf `CategoryPicker`, path labels in table
- **Categories:** unlimited-depth tree CRUD (cycle/duplicate guards), slide-over drawer, search, collapsed-by-default tree

- **Sales:** client-side search (receipt, client, amount); backend search SQL bug fixed

### Shopkeeper (POS + stock)
- **Browse:** `path` = array of **category UUIDs** via `computeTreeBrowseState` + `categories:getBrowseTree`

### Backend / release hardening
- `products:update` merges with existing row (partial updates e.g. active toggle no longer wipe `school_id`)
- `stock:getAll` + `favorites:list` → active products only (`p.is_active = 1`)
- `sales:create` validates stock qty + active product before deducting
- Category icons: `icon_data` BLOB (v6), `uploadIcon` / `getIcon` / `deleteIcon` IPC

### Still deferred / known gaps

- Plain/Badged as separate browse folders (name-based) — products live on **leaf** categories; badge via `school_id` + variant `attributes`
- CSV import path matching still basic; prefer admin UI for new products
- Unused preload stubs: `auth:logout`, `sync:push/pull`, `reports:stock`, `print:test` (no UI calls)

## Critical rules for any agent

1. **No dummy data** in production pages — use `window.api` only.
2. **Never run destructive seed** on client DB without `MWALIMU_SEED_RESET=1`.
3. **UUIDs** for all new DB rows in main process (`uuidv4()`).
4. **Products on leaf categories only** — `assertProductCategoryLeaf`; Schools branch not assignable as product category.
5. **IPC/main-process changes** require full Electron restart (not Vite HMR alone).
6. **Do not commit** unless the user asks.
