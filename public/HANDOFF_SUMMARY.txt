## What was completed recently (2026-05-26)

### Linear category taxonomy
- Navigation follows strict subdivision paths in `src/lib/hierarchyNav.js`:
  - **School Uniforms / Games / Footwear / Innerwear / Beddings:** `[Category → Subcategory → Product]`
  - **Schools → Londiani Christian Academy:** `[Schools → LCA → Primary | Junior Secondary → Product]`
  - **Other schools:** `[Schools → School name → Product]`
- Sidebar tree, POS grid, and stock pages share `computeBrowseState()` + `getNavSegments()`.
- Variant cards show breadcrumb path (e.g. `Schools › LCA › Primary`).

### POS UI (Visily-inspired)
- Dark glass theme (`src/styles/posTheme.js`), hierarchy sidebar, cart, favorites bar.
- **Touch / Dense** display mode (persisted in `displayModeStore`).
- Single-click variant → add 1 to cart; barcode scan support.

### Hierarchy sidebar default
- **Tree branches start collapsed.** User expands with ▸ / ▾.
- Implementation: `HierarchyTreeSidebar.jsx` uses `expandedNodes` (empty = all collapsed).

### Production-safe seeding
- `seed_sample_data.js` is **additive by default** — never deletes client data.
- Only inserts missing categories, school nodes, and products (skip if same name+category+subcategory+school).
- **Does not touch:** `clients`, `sales`, `sale_items`, `users`, `stock_movements`.
- Dev-only wipe: `MWALIMU_SEED_RESET=1 npx electron seed_sample_data.js` or `--reset`.

### Phase 4 (earlier)
- Sales master–detail, dashboard KPIs + recharts, thermal print + simulation, CSV import, POS favorites, stock quick-add.

## Critical rules for any agent

1. **No dummy data** in production pages — use `window.api` only.
2. **Never run destructive seed on client machines** without explicit `MWALIMU_SEED_RESET`.
3. **UUIDs** for all new DB rows in main process (`uuidv4()`).
4. **Do not commit** unless the user asks.
5. **Backend vs frontend:** stay in your role brief unless assigned Full Stack work.
