## IPC HANDLERS & PRELOAD

### New Handlers (add to `electron/ipc/handlers.js`)

**`categories:uploadIcon`** — Upload and store image
```javascript
{
  method: 'POST',
  input: {
    category_id: UUID,
    file: File object from frontend (will be converted to Buffer)
  },
  handler: async ({ category_id, file }) => {
    // 1. Validate: File size (<5MB), MIME (image/jpeg, image/png)
    // 2. Convert file to Buffer
    // 3. INSERT or UPDATE categories.icon_data WHERE id = category_id
    // 4. Return { ok: true, data: { category_id, size, mimeType } }
    // 5. On error: { ok: false, error: "message" }
  }
}
```

**`categories:getIcon`** — Retrieve image as data URL
```javascript
{
  method: 'GET',
  input: {
    category_id: UUID
  },
  handler: ({ category_id }) => {
    // 1. SELECT icon_data FROM categories WHERE id = category_id
    // 2. If icon_data is NULL: return { ok: true, data: null }
    // 3. If icon_data exists:
    //    - Detect MIME type from file header (first bytes: FFD8 = JPEG, 89 50 4E 47 = PNG)
    //    - Convert Buffer to Base64
    //    - Return data URL: `data:image/jpeg;base64,${base64}`
    // 4. On error: { ok: false, error: "message" }
  }
}
```

**`categories:deleteIcon`** — Remove image, keep emoji fallback
```javascript
{
  method: 'DELETE',
  input: {
    category_id: UUID
  },
  handler: ({ category_id }) => {
    // 1. UPDATE categories SET icon_data = NULL WHERE id = category_id
    // 2. Return { ok: true }
    // 3. On error: { ok: false, error: "message" }
  }
}
```

### Preload Updates (`electron/preload.js`)

Add to `window.api`:
```javascript
categories: {
  // ... existing calls
  uploadIcon: (payload) => ipcRenderer.invoke('categories:uploadIcon', payload),
  getIcon: (payload) => ipcRenderer.invoke('categories:getIcon', payload),
```

## EDGE CASES & GOTCHAS

1. **Large files:** BLOB storage in SQLite has soft limit ~1GB per database (not per cell), but we're limiting to 5MB per image. Should be fine for ~100 categories.

2. **Data URL size:** Base64 encoding inflates data by ~33%. A 5MB image becomes ~6.7MB in data URL. Browser can handle this, but consider caching data URLs in Zustand if rendering many at once.

3. **MIME detection:** Use file header bytes (magic numbers):
   - JPEG: `FF D8 FF`
   - PNG: `89 50 4E 47`
   - If in doubt, ask user to re-upload in correct format

4. **Concurrency:** If two admins upload icons simultaneously, SQLite locks will serialize writes (fine for small team).

5. **Offline:** All images stored in local SQLite DB, works offline (no cloud sync in this phase).
